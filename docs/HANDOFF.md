  | שירות | פרטי | ג'יפ |

- React Native, מסד נתונים SQL Server 2008, ועיצוב ברמה של מעצב גרפי מקצועי.

**סבב 2**

## 4. מה כבר בנוי ונבדק

**המבנה של הפרויקט**
- `database/` - שלושה סקריפטים שמריצים לפי הסדר: `01_schema.sql`, אחר כך `02_seed.sql`, ובסוף `03_v2.sql`.
  - כתובים כך שיעבדו ב-SQL Server 2008: בלי OFFSET/FETCH, בלי IIF, בלי THROW.
  - אפשר להריץ אותם שוב בלי נזק.
- `server/` - שרת Node 22 עם Express 5 ו-mssql. החיבור ל-SQL 2008 מוגדר עם `tdsVersion 7_3_A` ומאפשר TLS 1.0.
- `mobile/` - אפליקציית Expo SDK 57 עם expo-router. הממשק בעברית ומימין לשמאל, והיא עובדת באנדרואיד, באייפון ובדפדפן.
  - בלי כתובת שרת (`EXPO_PUBLIC_API_URL`) האפליקציה רצה במצב הדגמה עם נתונים לדוגמה.
  - במצב הדגמה קוד הכניסה הוא 1234, והטלפון 0521234567 הוא הבעלים.

**מה יש בתוך המערכת**
- תורים, מקדמות, ותוספות לשטיפה: ווקס, חישוקים, מנוע, מושבים, ריח.
- מועדון לקוחות, דירוגים, ורכבים של הלקוח.
- חנות: הזמנות, מלאי, ותנועות מלאי.
- סליקה מול CARDCOM, TRANZILA או מצב הדגמה. פרטי הסליקה נשמרים מוצפנים.
- מסמכים משפטיים עם גרסאות: תקנון, פרטיות, ביטולים, הצהרת נגישות.
- תיעוד של הסכמות הלקוח למסמכים, ביטול עסקה לפי חוק הגנת הצרכן, ומחיקת חשבון.
- יומן פעולות, והרשאות לפי דרגה.
- הגדרות נגישות באפליקציה: גודל טקסט, ניגודיות גבוהה, הפחתת תנועה.

**קבצי Windows** (בתיקייה הראשית של הפרויקט)
- `install.bat`:
  - מתקין Node אם חסר.
  - מעתיק את הפרויקט ל-`D:\AquaShine` ומריץ `npm ci`.
  - בונה את השרת ואת האתר (`web/`).
  - מריץ את `server\scripts\setup.mjs db`. הסקריפט שואל על פרטי SQL Server, יוצר את מסד הנתונים `CarWash` ומשתמש `carwash_app`, וכותב את `server\.env`.
  - פותח את פורט 4000 בחומת האש ויוצר קיצור דרך בשולחן העבודה.
- `start.bat` - מריץ את `node dist\index.js` בחלון בשם "AquaShine Server". הכתובות:
  - `http://localhost:4000` - האתר ללקוחות.
  - `http://localhost:4000/admin-login` - פאנל הניהול.
- `stop.bat` - עוצר את השרת.
- `build-apk.bat` - בונה APK בענן של Expo, לפי הפרופיל `apk` בקובץ `mobile/eas.json`.
  - שואל לאיזו כתובת שרת האפליקציה תתחבר, או `demo` לאפליקציית הדגמה.
  - צריך חשבון חינמי ב-expo.dev.

**מה נבדק (בענן, על SQL Server 2019 במצב תאימות ל-2008)**
- התקנה נקייה של מסד הנתונים.
- כל תהליכי השרת.
- 5 בדיקות יחידה, ובדיקת טיפוסים (tsc) בשרת ובאפליקציה.
- כניסה לפאנל הניהול בדפדפן כשהאתר מוגש מהשרת עצמו.

**מה לא נבדק**
- קבצי ה-BAT עצמם לא הורצו על Windows.
- ה-APK לא נבנה בפועל, כי הבנייה צריכה את חשבון ה-Expo של המשתמש.

## 5. המשימה הבאה שלך - התקנה במחשב של המשתמש

1. בדוק מה מותקן: `node -v`, `git --version`, וגרסת SQL Server ושם המופע.
   לבדיקת SQL Server: `sc query MSSQLSERVER` או `sc query "MSSQL$SQLEXPRESS"`.
2. וודא ש-SQL Server מוכן:
   - מצב התחברות משולב (Mixed Mode), ויש סיסמה ל-`sa`.
   - TCP/IP מופעל ב-SQL Server Configuration Manager.
   - השירות SQL Server Browser רץ, אם יש מופע עם שם.
   - אם SQL Server לא מותקן, שאל את המשתמש לפני שאתה מתקין. SQL Server 2008 כבר לא נתמך, אז אפשר להציע SQL Server Express עדכני. הקוד תואם גם לגרסאות חדשות.
3. הורד את הקוד (הפקודה בסעיף 2) ומשם הרץ את `install.bat` כמנהל.
   - לחלופין: שכפל ישירות ל-`D:\AquaShine` והרץ משם.
   - את התשובות ל-SQL ולסיסמת המנהל נותן המשתמש.
4. הרץ את `start.bat`. בדוק שהשרת עולה, שהפאנל נפתח, ושאפשר להיכנס עם המשתמש שנוצר בהתקנה.
5. כשמשהו נכשל, תקן בקוד, בצע commit ודחוף לענף הקיים.
6. בנה APK עם `build-apk.bat`: המשתמש מתחבר ל-Expo, והאפליקציה מכוונת לכתובת המחשב ברשת, בפורט 4000.
7. התקן את ה-APK בטלפון דרך הקישור או ה-QR, ובדוק כניסה עם SMS. עד שיש חברת SMS, הקוד מופיע בחלון השרת.

## 6. החלטות שממתינות למשתמש

- איזו חברת סליקה (Cardcom או Tranzila) ופרטי המסוף.
- איזו חברת SMS לשליחת קודי כניסה ותזכורות (כרגע `SMS_PROVIDER=console`).
- שעות ביום שישי. כרגע ראשון עד שישי 07:30–17:00, ושבת סגור.
- שם העסק, לוגו, מספר עוסק, ופרטי רכז הנגישות. את כולם ממלאים בפאנל תחת "הגדרות".
- כתובת ציבורית לשרת (דומיין עם HTTPS). בלעדיה אין סליקה אמיתית, והאפליקציה עובדת רק ברשת המקומית.
- האם להשאיר SQL Server 2008 או לשדרג.
- בדיקה של עורך דין למסמכים המשפטיים לפני העלייה לאוויר.
