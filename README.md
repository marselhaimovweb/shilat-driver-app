# אקווה שיין - אפליקציית תורים לשטיפת רכבים

אפליקציית React Native (Expo) ללקוחות ולמנהל העסק, שרת Node.js ומסד נתונים SQL Server 2008.

- **לקוחות**: כניסה עם SMS, תור להיום (תשלום במקום), תור עתידי עם מקדמה, תוספות לשטיפה, חנות ציוד עם סל ותשלום,
  היסטוריה, דירוג, כרטיסיית מועדון, ניהול רכבים, הגדרות נגישות, מחיקת חשבון.
- **ניהול** (לשונית "ניהול" באפליקציה - רק לבעלים/מנהלים/צוות, וגם בדפדפן): לוח בקרה חי, יומן תורים, תור ידני,
  מתגי הפעלה/כיבוי לכל מערכת, מחירון ותוספות, שעות פעילות וחגים, חוקי מקדמה וביטול, חנות ומלאי, לקוחות,
  צוות והרשאות, סליקת אשראי, מסמכים משפטיים, יומן פעולות, דוחות ודירוגים.
- **חוקיות**: תקנון, מדיניות פרטיות, ביטולים והחזרות, הצהרת נגישות, הסכמה מתועדת לפי גרסה - פירוט ב-[docs/SURVEY.md](docs/SURVEY.md).
  המסמכים אינם ייעוץ משפטי - יש להעביר לבדיקת עורך/ת דין לפני העלייה לאוויר.

סקר הדרישות המלא, מה נבנה ומה חסר: [docs/SURVEY.md](docs/SURVEY.md)

```
database/   סקריפטים ל-SQL Server 2008 (סכמה + נתוני התחלה)
server/     API ב-Node.js + Express + mssql
mobile/     אפליקציית Expo (אנדרואיד / אייפון / דפדפן)
docs/       סקר דרישות
```

## התקנה על מחשב Windows (כונן D) - קבצי BAT

לפני ההתחלה צריך במחשב SQL Server (2008 ומעלה) עם:
- **מצב התחברות משולב** (SQL Server and Windows Authentication) וסיסמה למשתמש `sa`.
- **TCP/IP מופעל**: ב-SQL Server Configuration Manager, תחת Protocols, מפעילים את TCP/IP ומפעילים מחדש את השירות.
  ב-Express עם שם מופע (למשל SQLEXPRESS) צריך שגם השירות SQL Server Browser ירוץ.

| קובץ | מה הוא עושה |
|---|---|
| `install.bat` | מתקין Node.js (אם חסר), מעתיק הכל ל-`D:\AquaShine`, בונה את השרת ואת פאנל הדפדפן, יוצר את מסד הנתונים `CarWash` ומשתמש `carwash_app`, כותב את `server\.env`, פותח את פורט 4000 בחומת האש ויוצר קיצור דרך בשולחן העבודה. כדאי להריץ בלחיצה ימנית ← "הפעל כמנהל". |
| `start.bat` | מפעיל את השרת בחלון נפרד ופותח את פאנל הניהול בדפדפן. מדפיס את הכתובת לטלפונים באותה רשת Wi-Fi. |
| `stop.bat` | עוצר את השרת. |
| `build-apk.bat` | בונה APK לאנדרואיד בענן של Expo (צריך חשבון חינמי ב-expo.dev). שואל לאיזה שרת האפליקציה תתחבר: כתובת המחשב ברשת המקומית, כתובת ציבורית, או `demo` לאפליקציית הדגמה. בסוף מתקבל קישור הורדה או QR להתקנה בטלפון. |

אחרי ההתקנה:
- פאנל ניהול: `http://localhost:4000/admin-login`, עם שם המשתמש והסיסמה שבחרתם בהתקנה.
- האתר ללקוחות: `http://localhost:4000`, ומטלפון באותה רשת: `http://<כתובת המחשב>:4000`.
- עד שמחברים חברת SMS, קודי הכניסה של הלקוחות מודפסים בחלון "AquaShine Server".
- טלפון עם ה-APK מתחבר לשרת רק כשהמחשב דולק, והטלפון באותה רשת (או כשיש לשרת כתובת ציבורית).
  אם כתובת המחשב ברשת משתנה, צריך לבנות APK מחדש. כדאי לקבוע לו כתובת קבועה בנתב.
- שמרו גיבוי של `D:\AquaShine\server\.env`. בלעדיו אי אפשר לפענח את פרטי חברת הסליקה שנשמרו.

## הרצה מהירה - מצב הדגמה (בלי שרת)

```bash
cd mobile
npm install
npx expo start
```

סורקים את ה-QR עם Expo Go בטלפון (או לוחצים `w` לדפדפן). בלי `EXPO_PUBLIC_API_URL` האפליקציה רצה
על נתוני דוגמה בזיכרון: קוד האימות הוא `1234`. המספר `052-1234567` הוא של בעלת העסק (רואה את לשונית "ניהול"),
כל מספר אחר הוא לקוח רגיל. בכניסת מנהל מהמחשב כל שם משתמש וסיסמה מתקבלים.

## הרצה מלאה עם SQL Server

### 1. מסד הנתונים
הריצו ב-SSMS (או `sqlcmd`) לפי הסדר:
```
database/01_schema.sql
database/02_seed.sql
database/03_v2.sql
```
הסקריפטים יוצרים את מסד הנתונים `CarWash` וניתן להריץ אותם שוב בבטחה. מסד נתונים קיים מהגרסה הקודמת - מריצים רק את `03_v2.sql`
(מוסיף דרגות, מסמכים משפטיים, תוספות, חנות, יומן פעולות, ומעדכן פעם אחת שעות 07:30-17:00 ו-4 עמדות).
צרו משתמש SQL ייעודי לאפליקציה עם הרשאות קריאה/כתיבה על `CarWash`.

### 2. השרת
```bash
cd server
cp .env.example .env     # מלאו פרטי חיבור, JWT_SECRET וסיסמת מנהל ראשונית
npm install
npm run dev              # פיתוח
npm run build && npm start   # ייצור
npm test                 # בדיקות לחישוב השעות הפנויות
```
בהפעלה הראשונה נוצר משתמש הבעלים לפאנל מתוך `ADMIN_USERNAME` / `ADMIN_PASSWORD`, והמסמכים המשפטיים נטענים.
כדי לנהל מהאפליקציה בטלפון: ניהול ← צוות והרשאות ← הוספת מספר הטלפון שלך כבעלים.

הערות ל-SQL Server 2008:
- `DB_TDS_VERSION=7_3_A` ל-2008, `7_3_B` ל-2008 R2.
- 2008 ללא עדכוני TLS תומך רק ב-TLS 1.0 - השרת מאפשר זאת לחיבור למסד בלבד. הריצו את מסד הנתונים ברשת פנימית.
- הגרסה אינה נתמכת עוד ע״י מיקרוסופט; הקוד תואם גם ל-SQL Server 2019/2022 Express (חינמי) - מומלץ לשדרג.

### 3. האפליקציה מול השרת
```bash
cd mobile
EXPO_PUBLIC_API_URL=http://<כתובת-השרת>:4000 npx expo start --clear
```
(`--clear` חשוב אחרי שינוי הכתובת - אחרת Metro משתמש בגרסה השמורה.)

## הגדרות שדורשות חשבון אצל ספק
| נושא | איפה מגדירים | מצב נוכחי |
|---|---|---|
| סליקה (מקדמות והזמנות) | בפאנל: ניהול ← סליקת אשראי (Cardcom / Tranzila) | מצב הדגמה. חובה לבדוק תשלום והחזר במסוף בדיקות |
| כתובת השרת לחברת הסליקה | `PUBLIC_URL` ב-`server/.env` | `https://.../api/payments/webhook/cardcom` |
| הצפנת פרטי הסליקה | `SETTINGS_ENCRYPTION_KEY` ב-`server/.env` | לשמור את המפתח - בלעדיו לא ניתן לפענח |
| SMS (קוד אימות, תזכורות) | `server/src/services/sms.ts` | הודעות מודפסות ללוג (`SMS_PROVIDER=console`) |

## הפאנל באינטרנט
```bash
cd mobile
EXPO_PUBLIC_API_URL=https://api.example.co.il npx expo export --platform web
```
מעלים את תיקיית `dist` לכל אחסון אתרים סטטי (לכל הנתיבים להחזיר את `index.html`). נכנסים ב-`/admin-login`
עם שם משתמש וסיסמה, או עם הטלפון - לבעלי הרשאה.

## בדיקות שבוצעו
- בדיקות יחידה לאלגוריתם השעות הפנויות (`server`, `npm test`).
- זרימה מלאה מול SQL Server במצב תאימות 2008 (compatibility level 100): כניסת OTP, רכב, תור רגיל,
  תור עתידי + מקדמה, חסימת חפיפה לפי מספר עמדות, סטטוסים, קיזוז מקדמה, ביטול עם/בלי החזר, דירוג,
  מחירים והיסטוריה, מתגים, ימים סגורים, דוחות.
- סבב 2, מול מסד נתונים חדש (01→02→03): חסימת הזמנה בלי הסכמה לתקנון, תוספות ומשך זמן, בקשת נגישות, החזר מקדמה
  לפי החוק, חנות (הזמנה, מלאי, חוסר מלאי, תשלום, משלוח, בקשת החזרה, זיכוי, החזרה למלאי), העלאת תמונת מוצר,
  הצפנת פרטי סליקה, חסימת מדיניות ביטול מעל 48 שעות, הרשאות (קידום לקוח למנהל, חסימת גישה לבעלים בלבד,
  הורדת הרשאה מיידית), גרסה חדשה של תקנון שמחייבת הסכמה מחדש, יומן פעולות, מחיקת חשבון.
- בדיקת טיפוסים (TypeScript) לשרת ולאפליקציה, ובדיקה חזותית של המסכים בדפדפן - במצב הדגמה ומול השרת האמיתי.
